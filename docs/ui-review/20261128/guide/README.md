## 측정과 조작

| 항목 | 브라우저 결과 |
| --- | --- |
| 360, 390px 초급 실습 | 소개가 293px에서 176px로 줄어 처음 화면에 더 많은 단계가 보인다. |
| 390px 전문가 조사 정책 | 본문 끝까지 스크롤했을 때 사본 생성 버튼은 변경 전에 524px 위로 이동했다. 변경 후 이동량은 0px이다. 총 생성 한도를 낮추면 필요한 동시 실행 선택을 다시 요청하며 선택을 끝낸 뒤 실제 사본을 연다. |
| 768, 1024, 1280, 1440px 생성 설명 | ‘이름과 시작 방법 설정’ 그림 확대창 폭은 730, 976, 1120, 1120px에서 각각 640px로 바뀌었다. 그림을 처음 열었을 때 강조된 템플릿 선택 영역까지 보인다. |
| 360, 390, 768, 1024, 1280, 1440px | 가이드 메뉴 여섯 개 전환, 이미지 확대, 모달 내 Tab 순환과 Escape 후 포커스 복귀, 목적별 템플릿 선택, 실습 상세 펼침, 조사 정책 오류 상태와 사본 생성을 검사했다. 두 실습 대화창의 axe-core WCAG 2.0–2.2 A·AA 자동 검사와 Chrome 오류 기록은 모두 0건이었다. |

## 화면 이미지 출처

Agent 생성, 가이드 시작, 작업 지시, 자료 원문, 시험 질문, 설계 오류와 도움말 화면 26개를 격리 작업실에서 촬영했다. 목적별 실습 10개는 실제 사본의 전체 보기와 하위 Workflow에서 다시 촬영했다. 연결도의 어두운 배경 위에서 ‘예약’, ‘규정 또는 미분류’, ‘근거 부족 또는 근거 상충’을 읽을 수 있는지 확인했다. 한국어 표식은 각 화면에서 촬영한 컨트롤 또는 블록의 경계에 맞췄다. 가이드의 기존 개념 일러스트는 방문자의 질문, 안내원이 읽는 자료, 전달하는 결과를 설명한다.

‘첫 실행의 답변’과 ‘지시를 바꾼 뒤의 실행 결과’는 이전 모델이 실제로 회원증 질문에 답했던 기록이다. 파일은 `04-answer.png`, `05-compare.png`, `quick-answer.webp`, `help-quoted-answer.webp`다. 이번 격리 환경에서 모델 연결 상태, 질문과 원문, 모델 연결 오류 및 답변 그림 확대를 확인했다. 실제 모델이 새로 답하는 경우는 미검증이다. [이전 답변 이미지 출처](../../precision-guide.md)

브라우저가 내려받은 가이드 이미지 40개를 디스크 파일의 SHA-256과 대조했다. 이미지의 한국어 대체 텍스트와 위치 표식 범위를 검사하고 가이드에서 실제 답변을 펼쳐 그림의 로딩, 확대, Escape 포커스 복귀를 확인했다. [파일별 확인](guide-assets.json) · [이미지 파일](../../../../public/guide/captures/)

## 찾을 수 없는 주소에서 돌아가기

최종 프로덕션 빌드에서 미등록 주소와 `/prototype/library`는 HTTP 404로 응답했다. Windows Chrome의 390px·1440px 창에서 밝은 테마와 어두운 테마 모두 한국어 제목을 표시했고, Tab으로 **작업실로 돌아가기**에 포커스를 옮긴 뒤 Enter로 로그인 화면에 도착했다. 8개 조합 모두 문서 가로 넘침과 예기치 않은 실행 오류가 없었다.
