# 업무 문서용 Workflow 만들기와 수정하기

## 가이드에서 업무 문서 만들기

**가이드 → 목적별로 만들기 → 업무 문서 만들기**에서 문서 유형을 고른다. **만들고 싶은 결과** 목록에서 마우스나 방향키로 항목을 선택한다. 문서를 선택하면 입력과 출력 예시를 함께 볼 수 있다. [업무별 입력과 출력 예시](WORKFLOW_USE_CASES.ko.md)

| 만들 문서 | 시작 방법 | 결과물 |
| --- | --- | --- |
| 할 일 앱 요구사항 | **내 사본으로 시작**을 누르고 편집기에서 **요구사항 작성 Agent → 속성 → 작업 지시**를 바꾼다. | 완료 항목을 숨기거나 다시 표시하는 동작을 설명한 요구사항 |
| 회의록·업무 보고 | **이 업무로 설계하기**를 눌러 예시 메모를 그대로 쓰거나 내 회의 메모로 바꾼다. | 확정 업무별 담당자·기한 표, 미결 안건, 결정 사항과 다음 회의 안건을 담은 두 문장 요약 |
| 반도체·제조 보고 | **이 업무로 설계하기**를 눌러 예시 CSV를 그대로 쓰거나 내 웨이퍼 정렬 오차 CSV로 바꾼다. | 허용 범위를 벗어난 측정 건수와 LOT 수, 해당 측정의 LOT·웨이퍼·정렬 오차 표 |

## 내 업무에 적용하기

회의록이나 제조 보고의 설계 창에는 요청문도 미리 들어 있다. 원하는 결과가 다르면 **맡길 일과 원하는 결과**의 문장을 고친다. **기본 설계로 시작**을 누르면 바로 블록을 편집할 수 있다. 작업실에 **모델 설정 필요**가 보이면 운영자에게 모델 연결을 요청한다. 기다리는 동안에도 기본 설계를 편집할 수 있다.

**모델 설정됨**이 표시되고 AI의 제안을 받고 싶다면 **초안 제안받기**를 누른다. AI는 요청문과 기본 예시로 블록 구성을 제안한다. 설계 검사를 통과하면 **내 Agent로 만들기**, 수정할 항목이 표시되면 **초안으로 열어 수정**을 누른다.

기본 설계를 쓰거나 AI 제안을 적용하면 설계 창의 메모나 CSV가 새 Agent의 입력 블록에 저장된다. 작업실에 **모델 설정됨**이 표시되면 편집기에서 **시험 실행**을 열고 **시험 질문**의 메모나 CSV를 확인한다. **질문 실행**을 눌러 문서를 생성한다.

- **회의록 작성 규칙.** 같은 계정에서 새 회의록 Agent를 만들면 **회의록 작성 Skill** 1판이 연결된다. 여기에는 원문에 담당자나 기한이 없으면 ‘미정’으로 표시하라는 규칙이 있다. 규칙을 바꾸려면 **도구 및 자료**에서 Skill을 수정하고 **새 버전 저장**을 누른다. 개정판을 쓸 프로젝트에서 **회의록 작성 Skill** 블록의 **고정할 자료 버전**을 새 판으로 바꾼다. [작업실 Agent에 지침 연결하기](PROJECT_SKILLS.md#workspace-agent-skills)
- **제조 기준표.** 새 제조 보고 Agent에는 **웨이퍼 정렬 오차 기준표** 1판이 연결된다. 허용 범위는 −4 nm 이상 +4 nm 이하이며 두 경계값을 모두 포함한다. 기준이 바뀌면 **도구 및 자료**에서 새 판을 저장하고, 적용할 Agent의 기준표 블록에서 **고정할 자료 버전**을 바꾼다. **시험 실행 → 실행 기록 → ＋ 새 대화**에서 같은 CSV를 보낸 뒤, 새 답변의 허용 범위와 범위를 벗어난 측정 건수를 이전 답변과 대조한다. 다른 Agent는 각자 연결한 기준표 버전으로 계속 판정한다. [기준표 새 판 적용 예시](WORKFLOW_USE_CASES.ko.md#manufacturing)

## 작업실에서 설계 바꾸기

| 변경 요청 | AI에 줄 자료와 지시 | 수정할 위치 |
| --- | --- | --- |
| 완료 항목 숨기기 동작을 명확히 하고 싶다 | 사용자 요청 원문과 ‘완료 항목 숨기기’를 켰을 때와 껐을 때 각각 목록에 표시할 항목 | 가이드나 예제 템플릿에서 요구사항 템플릿 사본을 열고 Agent의 **작업 지시**를 바꾼다. |
| 회의록을 인계 문서로 쓰고 싶다 | 확정 업무와 제안이 함께 있는 메모를 주고, 담당자·기한 열과 원문에 값이 없을 때의 ‘미정’ 표기를 요청한다. | 확정 업무 표, 다음 회의 안건, 요약의 순서를 바꾸려면 Agent의 **작업 지시**와 **회의록 작성 Skill**을 함께 확인한다. 원하는 순서와 표기 규칙을 Skill의 새 판에 적고 해당 프로젝트에 연결한다. 작업 지시에도 순서가 적혀 있다면 함께 고친다. |
| 개정한 제조 기준을 적용하고 싶다 | LOT·웨이퍼 식별자와 측정값이 담긴 CSV, 판정에 쓸 열·측정 단위·허용 범위·경계값 포함 여부·LOT 집계 방법을 적은 기준표 | 기준표를 새 판으로 저장한 뒤 적용할 Agent의 기준표 블록에서 **고정할 자료 버전**을 바꾼다. |

## 예시와 템플릿을 관리하는 파일
