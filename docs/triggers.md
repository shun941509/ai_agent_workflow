# 예약·이벤트 시작과 Workflow 재사용

## 자동 시작

1. 편집기에서 **시작 조건** 블록을 추가하고 **예약** 또는 **이벤트**를 선택합니다. 결과 블록까지 흐름과 입력값을 연결합니다.
2. 프로젝트 버전을 저장하고 게시합니다. 내 계정에서만 실행하려면 **나만 사용**으로 게시합니다.
3. 편집기의 **시험 실행 → 실행 설정 → 자동 시작**에서 **시작할 때 전달할 입력**을 채우고 **게시한 버전으로 활성화**를 누르세요. 자동 시작을 설정하거나 해제하려면 소유자 계정으로 로그인하세요. 다른 버전을 게시하거나 이전 판으로 복구하면 기존 예약이 즉시 일시 중지됩니다. 현재 게시판에서 일정과 시작 입력을 확인하고 **게시한 버전으로 예약 재개**를 누르면 다음 실행 시각이 표시됩니다. 이벤트의 이전 설정이 켜져 있으면 해제한 뒤 새로 게시한 버전으로 활성화하세요.
4. 예약은 `매일 09:00`(한국 시간), `매 15분`, `2027-01-01T09:00:00+09:00` 등으로 지정합니다. 실행기가 동작하는 동안에는 모델이 다른 질문을 처리하고 있어도 예약 시각마다 실행을 한 건씩 접수합니다. 실행기를 껐다 켜면 중단 중 놓친 예약은 설정마다 한 번씩 접수합니다. 이후 `매 15분`은 재시작 시각부터 15분 간격으로 접수하고, `매일 09:00`은 다음 한국 시각 오전 9시에 접수합니다.
5. 이벤트는 패널의 **기본 입력으로 이벤트 보내기**로 시험하거나, 활성화 때 표시된 주소로 HTTP POST를 보냅니다. Content-Type은 `application/json`, Authorization 헤더는 `Bearer <이벤트 토큰>`, 본문은 `{"eventId":"도착-42","input":"새 자료 요약"}`입니다. 토큰은 한 번 표시됩니다. 해제 후 다시 활성화하면 새 토큰이 발급됩니다. 같은 이벤트 번호와 입력을 재전송하면 이전 실행 번호를 반환합니다.

자동 시작도 실제 사용 환경의 실행 기록에 남습니다. 예약 생성처럼 승인이 필요한 행동에서는 **실행 기록**의 승인 화면에서 소유자의 응답을 기다립니다. 자동 시작 설정과 실행 기록은 소유자 계정으로 로그인한 상태에서 열 수 있습니다.

## 다른 Workflow 재사용

**Workflow 재사용** 속성의 **호출할 Workflow**에서 접근 가능한 프로젝트와 버전을 고릅니다. **정해진 단계에서 호출**은 현재 흐름에서 바로 호출하고, **Agent가 도구로 호출**은 참조선으로 연결한 Agent가 필요할 때 호출합니다. **이 블록 내부에 설계하기**를 선택하면 별도의 프로젝트를 연결하지 않고 내부 그래프를 작성할 수 있습니다.

버전을 선택하지 않으면 저장 시점의 게시판을 사용하며, 내 미게시 프로젝트에는 최근 저장판을 사용합니다. 자료와 하위 Workflow 버전은 대화 동안 고정되고, 재개할 때 원본 접근 권한을 다시 검사합니다. 공개 Agent에는 공개된 하위 Workflow 버전을 연결할 수 있습니다. 순환 참조는 검사에서 안내합니다.
