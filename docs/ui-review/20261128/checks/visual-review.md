# 최종 두 차례 화면 검토

Windows Chrome에서 20개 화면 상태를 밝은 테마의 360·390·768·1024·1280·1440px 창과 어두운 테마의 390·1440px 창으로 두 차례 촬영했다. 원본 160쌍 중 159쌍의 SHA-256이 일치했다. 1024px 가이드 한 쌍은 첫 단계 그림에만 차이가 있었다. RGB 채널 값이 8보다 많이 달라진 픽셀은 382개였고 두 그림의 **시험 실행** 표시와 화살표를 읽을 수 있었다. [최종 화면 비교](../index.html)

| 확인한 화면 | 두 차례에서 보인 결과 |
| --- | --- |
| 시험 실행을 연 직후 | 390×844px의 밝은·어두운 화면에서 입력값, **질문 실행**, 닫기 아이콘이 한 화면에 보인다. 버튼 아래 경계는 약 799px다. 밝은 1280·1440px와 어두운 1440px에서는 세 요소가 오른쪽 실행 영역에 보인다. [밝은 390px](../screens/after/390-run.webp) · [어두운 390px](../dark/after/390-run.webp) · [진입 위치 실측](run-entry.json) |
| 가이드 그림 | 밝은 1280·1440px와 어두운 1440px에서 실행 열기, 질문 보내기, 답변 확인의 한국어 단계와 표시 위치를 대조했다. 390px에서는 그림을 보려면 첫 설명 아래로 이동한다. [밝은 1280px](../screens/after/1280-guide.webp) · [어두운 1440px](../dark/after/1440-guide.webp) · [가이드 그림 검증](../guide/README.md) |
| 탐색과 역할 | 390px 상단 메뉴와 1280·1440px 측면 탐색의 활성 위치를 확인했다. 공유 수신자 화면에는 **Agent 사용**과 **내 사본 만들기**가, 소유자용 자료 화면에는 **수정**과 **자료 삭제**가 보인다. 운영자 전용 등록 양식은 역할별 측정에 따로 기록했다. [공유 수신자 390px](../dark/after/390-public-project.webp) · [메뉴와 역할별 기록](../workspace/README.md) |

390px에서는 답변이 추가된 뒤 다음 질문 입력 부분이 창 아래로 이어진다. 같은 실행 영역을 세로로 내려 다음 질문 입력과 실행 버튼에 접근할 수 있다. 두 차례 비교에서 주요 입력이나 버튼을 가리는 새 문제는 발견하지 못했다. [390px 실행 결과](../screens/after/390-run-result.webp)
