# 만들 수 있는 AI Agent 세 가지

1920×1080, 30 fps, 35초, 1,050프레임. 한국어. 시청자가 업무에 맞는 Agent 한 가지를 고르고 가이드의 문서 유형에서 찾는 것이 목표다.

배경은 크림색 #f6f2e8, 본문은 남색 #17274b, 표시 조건에는 청색 #284cba, 범위 밖 값에는 적갈색 #aa3c22를 쓴다. 연두색 #d9ec85는 허용 범위와 선택한 값의 바탕이다. Noto Sans KR와 Noto Serif KR를 로컬 글꼴로 사용한다. 주요 제목 72–112px, 본문 32–44px. 핵심 텍스트는 가로 192~1728px, 세로 108~972px 안에 둔다. 문서와 그래프를 정면으로 보고, 작업실 UI는 실제 Windows PC 화면을 사용한다. 임의의 앱 화면, 배경 글로우, 장식용 수치, 성능을 추정한 수치를 제외한다.

| 프레임 | 화면과 소리 |
| --- | --- |
| 0–119 | 어떤 Agent를 만들 수 있는지 묻는다. 문서 이름 세 개가 제자리에 놓인다. |
| 120–359 | 회의 메모에서 12부 인쇄와 담당자 민지가 확정 업무 표로 넘어간다. 20부 추가 인쇄는 다음 안건에 남는다. |
| 360–599 | 완료 항목을 잠깐 숨기고 싶다는 요청을 두 조건으로 나눈다. 켰을 때 사라지는 항목이 껐을 때 다시 나타난다. |
| 600–869 | 예제 CSV의 측정값 6개를 정렬 오차 축에 올린다. −4~+4 nm 바깥 3건과 해당 LOT 2개를 표시한다. |
| 870–1049 | 실제 가이드의 업무 문서 선택지를 보여 준다. 음악을 페이드아웃한다. |

세 표본은 프로젝트의 업무 문서 가이드에 실린 예시다. 입력 및 결과 설명을 읽을 수 있는 시간은 각 2초 이상을 확보한다. 움직임은 0.3~0.8초로 제한하고 power2.out 또는 power3.out으로 마무리한다. 마지막 MP4에서 다섯 장면, 첫 프레임과 마지막 프레임, 한글 글자, 음악과 효과음, 가이드 선택지의 가독성을 확인한다.
