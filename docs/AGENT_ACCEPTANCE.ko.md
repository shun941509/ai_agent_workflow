## 실제 모델 통합 시험

프로젝트의 모델 설정을 읽어 게시된 Agent를 실행하고, 조회·취소·생성 도구에서 모델이 선택한 도구와 인자를 확인한다. 격리된 SQLite와 도서관 MCP에서 승인 전 예약·영수증 각 0건, 중복 승인 및 두 워커의 동시 처리 후 각 1건, 별도 거절 후 추가 0건을 검사한다. 답변에 적힌 예약 번호도 실제 예약과 대조한다. `pnpm test:live`에 포함되며, 이 시험만 실행할 때는 `node --import tsx tests/live-tool-approval.ts`를 사용한다. [실제 모델 시험](../tests/live-tool-approval.ts)
