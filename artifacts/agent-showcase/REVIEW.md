# 영상 검토

## 사례와 화면

회의록 작성 Agent는 자료에서 확정된 인쇄 수량 12부, 담당 민지, 기한 미정을 옮긴다. 추가 20부는 미결 안건에 표시한다. 요구사항 작성 Agent는 완료 항목을 숨겼다가 되돌려 보고 싶다는 요청을 설정의 두 가지 표시 조건으로 풀어낸다. 화면 속 목록에는 '동작 예시'라고 표기했다. 제조 보고 Agent는 예제 CSV의 여섯 측정값을 보여 준다. 허용 범위 −4~+4 nm는 양끝을 포함한다. L7의 +5 nm, −7 nm와 L8의 +6 nm가 범위를 벗어난다. [세 사례의 원문](../../docs/WORKFLOW_USE_CASES.ko.md)

마지막 장면의 메뉴는 별도 로컬 실행 환경에서 연 현재 작업실의 실제 가이드 화면이다. Windows Chrome 1,440×900 창에서 요소 영역 249×217 CSS 픽셀을 3배율로 캡처했다. 1,280px와 1,440px 창에서 같은 세 항목의 이름과 순서를 확인했다.

## 편집과 검증

세 개의 문서 표본을 연속해서 펼치는 구성을 선택했다. 한 건의 측정값을 추적하는 구성과 회의 메모 한 장을 따라가는 구성은 [구성안](STORYLINES.md)에 보관했다. 첫 장면의 색인을 따라 회의 메모, 요청 문장, 측정값을 확인할 수 있다.

다섯 장면의 시작과 중간, 네 컷 경계, 다음 회의 안건이 나타난 시점, 할 일 설정 복원 후 화면을 검토했다. '켜짐'과 '꺼짐'을 30px로 키웠다. 제조 장면은 여섯 점의 위치, +와 − 부호, 행 식별자를 각 CSV 행과 대조했다. 식별자가 가장 조밀한 장면이므로 최종 수치와 해당 LOT를 화면 아래에도 따로 적었다.

두 Windows PC 창 크기에서 HyperFrames 편집기가 프로젝트를 열고 한글 글꼴 두 개, 가이드 이미지, 오디오를 읽는 것을 확인했다. 음악과 효과음의 사용 조건은 [크레딧](CREDITS.md)에 기록했다.

## 완성 파일

HyperFrames 0.9.104의 최종 검사에서 280개 시점을 확인했다. 오류 0건, 경고 0건이다. 이 PC의 기본 내보내기가 브라우저 초기화 단계에서 지연되어, HyperFrames의 프레임 캡처를 0초부터 34.966667초까지 정확히 1/30초 간격으로 출력했다. 1,050개 시점과 순번을 확인해 FFmpeg로 인코딩했다.

[완성 MP4](../ai-agent-workflow-showcase.mp4)는 35.000초, 1920×1080, 30fps H.264 영상과 48kHz 스테레오 AAC 오디오로 구성된다. 파일 크기는 2,238,693바이트다. 첫 프레임과 끝 프레임을 포함해 일곱 시점에서 MP4를 다시 디코딩해 기준 이미지와 대조했다. 480×270에서 채널별 평균 절대 오차는 255단계 중 1.64~2.40이었다. 마지막 장면과 파일 메타데이터에 음원의 저작자와 편집 사실을 기록했다.

음량은 −16.4 LUFS, 트루 피크는 −1.3 dBTP, 클리핑은 0회로 측정했다. 오디오 검증은 신호 측정으로 진행했다.
