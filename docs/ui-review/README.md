# Windows PC 화면 비교

| 확인할 화면 | 보관한 자료 |
|---|---|
| 전체 작업실·다크 모드·권한별 조작 | 2026년 11월 28일의 [20개 화면 전후 비교](20261128/index.html)와 [컴포넌트별 검증 근거](20261128/components.md). 360~1440px의 분할 창, 자료 편집, 실행, 가이드와 키보드 조작을 포함한다. |
| 작업실 홈과 편집기 전체 보기 | 2026년 11월 26일 1440px에서 촬영한 [변경 전후 두 쌍](index.html) |
| 가이드와 실습 | 11월 27일 Chrome 1440px의 [가이드 캡처 19장](guide.html). 화면에서 읽을 수 있는 예시 질문, 인용, 실행 버튼과 오류 안내를 포함한다. |
| 오류 복구 | 같은 날짜의 1440px Chrome에서 로그인 통신 오류, 공유 주소 복사, 사본 요청 중 뒤로 가기, 가이드 선택과 이벤트 토큰 복사를 시험한 [변경 전후 여섯 쌍](recovery.html) |
| 편집기 헤더 | 추천 수준과 도구 배치를 확인할 수 있는 [변경 전후 캡처](dense-names.html)와 [시험 기록](dense-names.md) |
| 화면과 조작 요소 | 홈·가이드·편집기·공유 설정 등의 [10개 상태 전후 비교](precision.html) |
| 계정과 자료 관리 | [33개 화면의 전후 비교](precision-data.html). 화면 폭과 캡처 범위를 선택해 같은 상태의 등록·공유·삭제 동작을 비교한다. |

[편집기와 실행](precision-editor.md), [자료와 계정](precision-data.md), [홈과 가이드](precision-guide.md)에는 화면 조작과 결과를 기록했다. 당시 수정한 파일은 [변경 파일 목록](precision-files.md)에 있다. 현재 Windows PC 인수 기준과 최근 측정값은 [QA 보고서](../QA-REPORT.md)에서 확인할 수 있다.
