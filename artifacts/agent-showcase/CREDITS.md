# 제작 자료

음악은 Kevin MacLeod의 *Galactic Rap*이다. 원곡에서 35초를 발췌하고 처음과 끝의 음량을 조정한 뒤 효과음과 혼합했다. [원곡](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN2300009) · [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

효과음은 프로젝트의 HyperFrames media-use 번들에 수록된 Pixabay 녹음을 사용했다. [효과음 라이선스](https://pixabay.com/service/license-summary/)

문서와 요구사항, 제조 수치의 원본은 [작업실 업무 문서 가이드](../../docs/WORKFLOW_USE_CASES.ko.md)다. 마지막 화면은 Windows Chrome에서 실제 작업실 가이드를 캡처했다. 작업실 아이콘은 저장소의 [원본](../../public/studio-icon.svg)을 사용했다.

로컬 Noto Sans KR 및 Noto Serif KR 서브셋 배포 조건은 [고딕 글꼴 라이선스](assets/fonts/NotoSansKR-OFL.txt)와 [명조 글꼴 라이선스](assets/fonts/NotoSerifKR-OFL.txt)에 있다.
