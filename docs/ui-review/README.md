11월 27일 첫 인계 빌드에서 7개 너비를 두 차례 검토한 기록과, 이후 320px 연결도에서 작은 조작점 8개를 개선하고 다시 측정한 결과는 [QA 보고서](../QA-REPORT.md)에 있다.

최종 가이드의 그림 24장은 제품을 390px와 1440px로 열어 촬영했다. Agent가 도서관 규정에서 답을 찾는 과정, 새 Agent 만들기, 시험 실행 세 단계와 핵심 기능을 살펴볼 수 있다. 업무 도우미·문서 정리·정보 조사·반복 업무 사례는 입력과 결과를 보여 준다. 문제 해결 화면에는 질문 실행, 자료 근거, 작업 지시, 모델 연결을 점검하는 위치가 나온다. [최종 시각 자료](guide.html#visual-concept)

같은 날 앞서 촬영한 초판의 22장도 보존했다. 첫 화면과 전체 페이지를 각각 네 너비에서 전후 비교하고 모바일과 데스크톱에서 당시의 세 단계 그림, 질문 비교와 펼친 도움말을 볼 수 있다. [초판 전후 비교](guide.html#earlier)

제품을 320·390·768·1440px로 열어 사례 네 가지에서 각각 예제 미리보기를 열고 뒤로 가기를 실행했다. 16번 모두 원래 사례와 키보드 포커스를 복원했다. 오프라인 갤러리에서도 내장 이미지 46장의 크기와 연결 대상을 대조했다. 네 너비의 기본·원본 보기에서 키보드 이동, 원본 크기 스크롤과 가로 넘침을 점검했고 여덟 상태의 axe 위반, 외부 HTTP 요청, 예상 밖 콘솔 출력은 0건이었다.

11월 27일 자료는 로그인 요청 중 네트워크 끊김과 Agent 공유 설정에서 클립보드 쓰기가 불가능한 상황을 390·768·1440px로 비교한다. 공유 설정은 대화상자 영역을 촬영했다. 수정 후 그림의 주소 입력란은 시험용 링크를 가렸으며 세 너비 모두 실제 입력란으로 포커스가 이동해 주소 전체가 선택되는 것을 확인했다.

사본 생성 비교 두 쌍은 1440px에서 공개 Agent의 사본을 요청하고 브라우저 뒤로 가기로 **내 Agent**를 연 뒤 늦게 도착한 실패와 성공 응답을 보여 준다. 성공한 경우 사본 한 개가 목록에 나타났고 실패한 경우 사본은 생기지 않았다.

마지막 두 쌍은 복사 권한 응답을 기다리는 동안 사용자가 계속 작업한 경우다. 수정 후 가이드에서는 마지막에 선택한 질문을 유지한다. 이벤트 토큰을 다시 발급하면 이전 복사의 성공 안내가 새 토큰에 표시되지 않는다. 토큰과 이벤트 주소는 촬영할 때 양쪽 화면 모두에서 가렸다.

오프라인 Chrome에서 이 자료의 그림 20장을 모두 열어 원본 너비와 높이를 확인했다. 갤러리를 320·390·768·1440px로 열어 기본·원본 보기의 키보드 이동, 확대 스크롤, 문서 가로 넘침을 검증했다. 여덟 상태에서 axe 위반, 예상 밖 콘솔 출력, 외부 HTTP 요청은 0건이었다.

## 11월 26일 서비스 개편 비교

2026년 11월 26일 Workflow Studio에서 촬영한 아홉 쌍의 실제 화면이다. 처음 방문한 홈, 실습 상세, 큰 연결도와 모바일 편집기, 시험 실행 결과, 자료 목록, 긴 제목·긴 원문, 잘못된 주소를 담았다. 캡처는 격리된 시험 계정과 실습 자료로 만들었다. HTML 파일 하나에 그림과 스타일이 들어 있어 파일을 복사해 오프라인에서 열 수 있다. 각 쌍은 같은 너비와 높이에서 촬영했고 **원본 크기로 보기**로 실제 캡처 픽셀을 읽을 수 있다.

홈에서 자료 목록까지의 여섯 쌍은 최초 개편 전과 두 번째 전체 검토 시점의 제품을 비교한다. 뒤의 세 쌍은 승인된 디자인에서 추가로 재현한 문제와 수정 결과다. 원문은 520개 조항을 끝까지 읽을 수 있는지 실제로 저장한 문서로 확인했고, 비교 그림은 화면 맨 위만 보여 준다.

11월 27일 오프라인 Chrome에서 그림 18장을 열어 원본 크기를 대조했다. 320·390·768·1440px에서 확대 전후의 가로 넘침을 검사하고, 키보드로 캡처에 진입해 오른쪽 끝 방향으로 스크롤했다. 여덟 화면 상태의 axe 검사에서 위반이 0건이었고, HTTP 요청과 콘솔 오류도 0건이었다.
