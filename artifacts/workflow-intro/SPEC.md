# 도서관 안내 Agent · 영상 설계

처음 보는 사람이 자료를 연결한 Agent가 규정의 변경을 답변과 내려받을 파일에 반영한다는 점을 이해하고, 예제 템플릿에서 같은 실습을 찾을 수 있어야 한다.

## 형식과 화면

- 가로 1920 × 1080, 30 fps, 30초, 총 900프레임. 한국어 화면 문구와 짧은 효과음.
- 종이색 `#f6f2e7`, 글자색 `#123c36`, 짙은 초록 `#10493f`, 연두 `#d5ef93`, 교정색 `#a43939`. 기존 제품 화면은 원본 색을 유지한다.
- Noto Serif KR 700–800과 Noto Sans KR 500–750. 주제 문구 80–106px, 보조 문구 30–44px. 주요 문구는 화면 좌우 192px, 상하 108px 안쪽에 둔다.
- 책등과 대출 카드는 영상에만 쓰는 삽화다. 편집기, 도서관 규정 원문과 시험 결과는 저장소가 보관한 Windows PC 캡처에서 자른다.
- 정면 구도, 한 컷에 한 가지 조작. 이동은 9–24프레임 동안 power2.out 또는 power3.out, 주요 값은 도착 후 2초 이상 유지한다. 첫 프레임에서도 질문을 읽을 수 있다.

## 쇼트

| 프레임 | 화면과 동작 |
| --- | --- |
| 0–149 | 도서관 창구의 질문과 책 세 권. 책이 차례로 들어오며 첫 화면을 구성한다. |
| 150–329 | 작업실의 실제 연결도. 도서관 이용규정과 도서관 안내 Agent의 연결을 보여 준다. |
| 330–539 | 규정의 대출 한도를 3권에서 5권으로 고친다. 원문과 수정값을 실제 편집기 크롭으로 확인한다. |
| 540–719 | 5권이 표시된 시험 결과를 보여 준다. 종이 형태의 안내 파일이 답변 옆에 등장한다. |
| 720–899 | 작업실 이름과 초급 실습 경로를 안내한다. 첫 컷의 책등을 다섯 권으로 완성한다. |

검토 대상은 장면별 첫 프레임과 중간 프레임, 컷 경계 전후, MP4의 마지막 프레임이다. 한글 누락, 실제 캡처의 잘못된 크롭, 읽기 전 컷 전환, 첫 화면 공백, 잘린 책 제목을 확인한다. 인위적인 가짜 UI, 입체로 기울인 제품 화면, 장시간의 페이드, 글로우 효과를 제외한다.
