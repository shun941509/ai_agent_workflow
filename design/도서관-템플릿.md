# 도서관 안내 Agent 체험 과제

이 문서는 가상 도서관을 배경으로 수준별 체험 과제 다섯 가지를 제안한 **초기 설계 기록**이다. 아래 질문·안내문·버튼명은 당시 시안을 따른다. 현재 앱의 도서관 실습 8개와 화면별 조작 방법은 [첫 실습 가이드](../docs/FIRST_WORKFLOW_GUIDE.md)에서 확인할 수 있다.

각 과제는 원하는 수준부터 시작할 수 있도록 완성된 Workflow와 시험 질문을 함께 제공한다. 먼저 예제를 실행한 뒤 내 사본에서 한 가지를 바꾸고, 같은 질문을 보내 두 결과를 비교한다.

## 예시 안내문

| 자료 | 안내문에 적힌 내용 |
|---|---|
| 운영시간 | 평일에는 오전 9시부터 오후 6시까지, 토요일에는 오전 10시부터 오후 4시까지 엽니다. 일요일은 휴관합니다. |
| 대출 규정 | 한 사람의 대출 한도는 3권입니다. |
| 회원증 발급 | 회원증을 처음 만들 때는 신분증을 가져오세요. |
| 문의처 | 이용 안내는 1층 안내데스크에서 도와드립니다. |

예시 안내문에는 분실물 보관 기간을 싣지 않았다. 자료에 답이 없는 질문에 Agent가 어떻게 대응하는지 살펴보기 위해서다. 각 과제에서는 답변 내용과 실행 기록에 나타난 블록을 함께 보고 완료 여부를 판단한다.

## 입문 · 질문을 바꿔 답변 받아보기

**흐름**　질문 입력 → 안내 Agent → 답변

1. “토요일에도 여나요?”라고 묻는다. 토요일 운영시간이 오전 10시부터 오후 4시까지라고 답하는지 확인한다.
2. “회원증을 만들려면 무엇을 가져가나요?”라고 묻고 준비물로 신분증을 안내하는지 확인한다.
3. **안내 Agent** 블록에서 답변 지시를 “답을 먼저 쓰고, 다음 줄에 안내문의 근거 문장을 붙여 주세요.”로 바꾼다. 같은 회원증 질문을 다시 보낸다.

**완료 기준**　작업 지시를 바꾸기 전후에 같은 회원증 질문을 보냈을 때 두 답변 모두 신분증을 안내한다. 두 번째 답변에는 “회원증을 처음 만들 때는 신분증을 가져오세요.”라는 근거가 붙는다. 세 블록을 차례로 선택해 내가 입력한 질문과 생성된 답변이 어디로 전달됐는지 찾을 수 있다.

## 초급 · 내 안내자료로 답하게 만들기

**흐름**　질문 입력 → 대출 규정을 참고하는 안내 Agent → 근거가 담긴 답변

1. “책을 몇 권까지 빌릴 수 있나요?”라고 묻는다. 답변에 대출 한도가 3권이라고 나오는지, 인용한 문장이 안내문과 일치하는지 확인한다.
2. 내 사본에서 안내 Agent의 참고 자료를 열고 “한 사람의 대출 한도는 5권입니다.”를 붙여 넣어 기존 규정을 교체한다.
3. 같은 질문을 다시 보낸다. 대출 한도가 3권에서 5권으로 바뀌었는지, 두 답변이 각각 그때 사용한 안내문의 문장을 인용했는지 확인한다.

**완료 기준**　내 사본의 답변에는 대출 한도 5권과 새 근거 문장이 함께 나온다. 원본 템플릿의 안내문에는 대출 한도가 여전히 3권으로 적혀 있다.

## 중급 · 답을 모를 때의 경로 만들기

**흐름**　질문 입력 → 근거 찾기 → 근거 있음 / 근거 없음 → 각 경로의 답변

1. “책을 몇 권까지 빌릴 수 있나요?”로 근거가 있는 경로를 확인한다. 기본 답변은 대출 한도 3권과 근거 문장을 제시한다.
2. “분실물은 며칠 보관하나요?”라고 묻는다. 근거가 없는 경로에서는 보관 기간을 확인할 수 없다고 답하고 1층 안내데스크를 문의처로 알려 준다.
3. 내 사본에서 `근거 없음`의 다음 블록을 `추가 질문`으로 바꾼다. “확인하고 싶은 지점이나 가지고 계신 안내문을 알려 주시겠어요?”라고 묻도록 설정하고 두 질문을 다시 실행한다.

**완료 기준**　경로를 바꾼 뒤에도 대출 질문에는 3권이라고 답한다. 분실물 질문을 받으면 경로를 바꾸기 전에는 1층 안내데스크를 안내하고, 바꾼 뒤에는 추가 정보를 요청한다. 어느 경우에도 보관 기간을 추측하지 않는다. 실행 기록에서 두 질문이 각각 어느 분기로 진행됐는지 확인할 수 있다.

## 고급 · 두 담당자의 답변 합치기

**흐름**　방문 질문 → 운영시간 담당과 회원증 담당이 각각 확인 → 두 결과 합치기 → 방문 안내

1. “토요일에 처음 회원증을 만들러 가요. 언제 가고 무엇을 가져갈까요?”라고 묻는다. 두 담당자가 각각 운영시간과 준비물의 근거를 반환하는지 확인한다.
2. 내 사본에서 회원증 담당의 참고 자료 연결만 해제한다. 같은 질문으로 다시 실행한다.
3. 실행 기록에서 두 담당자의 답변을 열고 각각 어떤 근거를 찾았는지 확인한다. 이어서 이용자에게 보인 최종 답변에서 두 담당자의 결과를 찾는다.

**완료 기준**　첫 방문 안내는 토요일에 오전 10시부터 오후 4시까지 문을 열며, 회원증을 만들려면 신분증이 필요하다고 설명한다. 두 번째 안내에는 같은 운영시간이 나오고, 준비물은 추가 확인이 필요하다고 표시된다.

## 전문가 · 규정 변경을 검증하고 배포하기

**흐름**　공개 중인 1판 → 2판 초안 작성 → 같은 시험 질문으로 비교 → 새 버전 공개 또는 이전 버전 복구

1. 내 체험용 Agent의 1판을 기준으로 삼는다. 2판 초안에서 대출 규정만 “한 사람의 대출 한도는 5권입니다.”로 교체한다.
2. 아래 질문 세 개를 1판과 2판 초안에 각각 보내 총 여섯 번 실행한다. 두 판의 답변과 인용을 대조한다. 대출 한도만 3권에서 5권으로 바뀌고 일요일 휴관과 분실물 문의처 안내는 같은지 확인한다.

| 시험 질문 | 1판 | 2판 초안 |
|---|---|---|
| 책을 몇 권까지 빌릴 수 있나요? | 3권과 1판의 대출 근거 | 5권과 2판의 대출 근거 |
| 일요일에도 여나요? | 일요일 휴관 | 일요일 휴관 |
| 분실물은 며칠 보관하나요? | 기간 확인 필요, 1층 안내데스크 안내 | 같은 안내 |

3. 초안을 저장한 뒤 공유 링크에서 새 대화를 열고 대출 한도 3권을 확인한다. 시험 결과가 기준에 맞으면 시안의 `새 버전 공개`를 누른다. 같은 링크에서 새 대화를 열어 5권을 확인한다.
4. 1판을 다시 공개한 뒤 같은 링크에서 새 대화를 열어 대출 한도를 묻는다.

**완료 기준**　같은 공유 주소에서 각 시점에 시작한 새 대화는 초안 저장 후 3권, 2판 공개 후 5권, 1판 복구 후 3권을 안내한다. 어떤 시험 결과를 근거로 공개를 결정했는지 설명할 수 있다.

## 현재 앱에서 따라 할 때

| 실습 | 현재 앱에서 확인할 점 |
|---|---|
| 입문 | 기본 질문은 회원증을 만들 때 무엇을 준비해야 하는지 묻는다. **도서관 안내 Agent**의 **작업 지시**를 바꾼 뒤 새 대화에서 같은 질문을 보낸다. |
| 초급 | 5권으로 고친 사본에서 화면의 답변·인용과 **대출안내.txt**를 대조한다. 템플릿에서 새 사본을 하나 더 만들면 원래 규정인 3권을 확인할 수 있다. |
| 중급 | 분실물 보관 기간을 물으면 추가 질문을 받는다. 첫 대화에서는 ‘분실물은 14일간 보관합니다’라고 적힌 안내문으로 회신한다. 새 대화에서 같은 질문을 보내고 이번에는 지점명만 회신한다. 첫 답변이 14일을 인용하고 두 번째 답변이 보관 기간을 확인할 수 없다고 안내하는지 비교한다. |
| 전문가 | **예제 템플릿**의 **실습 수준**에서 **전문가**를 고르고 **규정 변경 검증·게시·복구 → 내 사본으로 시작**을 누른다. 이 사본에는 기준판과 후보판, 시험 사례와 **게시 판단** 양식이 준비돼 있다. |

게시 실습에서 승인된 변경은 대출 한도를 3권에서 5권으로 높이는 것뿐이다. 현재 앱의 2판에는 일요일에도 문을 연다는 규정이 들어 있다. 두 판에 같은 일요일 질문을 보내 1판의 휴관 안내와 2판의 답변을 비교한다.

실습 사본의 **공유 설정**에서 **대상 버전**을 고른다. **게시 판단**에서 후보판은 **게시** 또는 **게시 보류**, 이전 판은 **이전 판으로 복구**, 현재 게시한 판은 **현재 게시판 유지**를 선택할 수 있다. 일요일 답변이 어떻게 달라졌고 이 차이가 게시 결정에 어떤 영향을 주었는지 **판단 근거**에 적고 **판단 적용 및 기록**을 누른다. 공유 주소에서 새로 시작한 대화에는 현재 게시 버전이 적용되고, 기존 대화에는 시작 당시의 버전이 적용된다.
