# 도서관 안내 Agent 체험 과제

다섯 템플릿은 같은 가상 도서관의 안내문을 사용한다. 원하는 단계에서 바로 시작할 수 있다. 각 템플릿에는 완성된 Workflow와 시험 질문이 들어 있다. 먼저 예제를 실행한 뒤 내 사본에서 한 가지를 바꾸고 같은 질문으로 차이를 확인한다.

## 예시 안내문

| 자료 | 안내문에 적힌 내용 |
|---|---|
| 운영시간 | 평일에는 오전 9시부터 오후 6시까지, 토요일에는 오전 10시부터 오후 4시까지 엽니다. 일요일은 휴관합니다. |
| 대출 규정 | 한 사람의 대출 한도는 3권입니다. |
| 회원증 발급 | 회원증을 처음 만들 때는 신분증을 가져오세요. |
| 문의처 | 이용 안내는 1층 안내데스크에서 도와드립니다. |

분실물 보관 기간은 비워 둔다. 자료에 답이 없는 질문을 했을 때 Agent가 어떻게 대응하는지 살펴보기 위한 설정이다. 아래의 완료 기준은 답변의 의미와 실제로 거친 블록을 기준으로 읽는다.

## 입문 · 질문을 바꿔 답변 받아보기

**흐름**　질문 입력 → 안내 Agent → 답변

1. 준비된 질문 **“토요일에도 여나요?”**를 실행한다. 답변에는 토요일 운영시간인 오전 10시부터 오후 4시까지가 담긴다.
2. 질문을 **“회원증을 만들려면 무엇을 가져가나요?”**로 바꿔 실행한다. 답변이 신분증을 안내하는지 확인한다.
3. 가운데 블록을 눌러 답변 지시를 **“답을 먼저 쓰고, 다음 줄에 안내문의 근거 문장을 붙여 주세요.”**로 바꾼다. 같은 회원증 질문으로 다시 실행한다.

**완료 기준**　마지막 두 실행에서 입력과 준비물은 같고, 수정 후 답변에는 “회원증을 처음 만들 때는 신분증을 가져오세요.”라는 근거가 붙는다. 세 블록을 차례로 선택해 내가 입력한 질문과 생성된 답변이 어디로 전달됐는지 찾을 수 있다.

## 초급 · 내 안내자료로 답하게 만들기

**흐름**　질문 입력 → 대출 규정을 참고하는 안내 Agent → 근거가 담긴 답변

1. **“책을 몇 권까지 빌릴 수 있나요?”**를 실행한다. 한도 3권과 이를 뒷받침하는 문장을 확인한다.
2. 내 사본에서 안내 Agent의 참고 자료를 열고 **“한 사람의 대출 한도는 5권입니다.”**를 붙여넣어 기존 규정을 교체한다.
3. 같은 질문으로 다시 실행해 답변의 숫자와 근거 문장을 각각 비교한다.

**완료 기준**　내 사본에서는 한도 5권과 새 근거 문장이 함께 나온다. 원본 템플릿을 열면 처음 안내문인 3권을 확인할 수 있다.

## 중급 · 답을 모를 때의 경로 만들기

**흐름**　질문 입력 → 근거 찾기 → 근거 있음 / 근거 없음 → 각 경로의 답변

1. **“책을 몇 권까지 빌릴 수 있나요?”**로 근거가 있는 경로를 확인한다. 기본 답변은 대출 한도 3권과 근거 문장을 제시한다.
2. **“분실물은 며칠 보관하나요?”**로 근거가 없는 경로를 확인한다. 기본 답변은 보관 기간을 확인할 수 없다고 알리고 1층 안내데스크로 안내한다.
3. 내 사본에서 `근거 없음`의 다음 블록을 `추가 질문`으로 바꾼다. **“확인하고 싶은 지점이나 가지고 계신 안내문을 알려 주시겠어요?”**라고 묻도록 설정하고 두 질문을 다시 실행한다.

**완료 기준**　대출 질문에는 이전처럼 답하고, 분실물 질문에서는 추가 정보를 요청한다. 실행 경로에서 해당 분기를 찾을 수 있고 두 답변 모두 임의의 보관 기간을 제시하지 않는다.

## 고급 · 두 담당자의 답변 합치기

**흐름**　방문 질문 → 운영시간 담당과 회원증 담당이 각각 확인 → 두 결과 합치기 → 방문 안내

1. **“토요일에 처음 회원증을 만들러 가요. 언제 가고 무엇을 가져갈까요?”**를 실행한다. 두 담당자가 각각 운영시간과 준비물의 근거를 반환하는지 확인한다.
2. 내 사본에서 회원증 담당의 참고 자료 연결만 해제한다. 같은 질문으로 다시 실행한다.
3. 최종 답변과 각 담당자의 출력을 열어, 어느 담당자가 무엇을 확인했는지 비교한다.

**완료 기준**　첫 실행에는 토요일 오전 10시~오후 4시와 신분증이 함께 나온다. 두 번째 실행에서는 운영시간을 그대로 알려주고, 준비물은 추가 확인이 필요하다고 명시한다. 운영시간 담당의 결과는 회원증 자료가 빠져도 전달된다.

## 전문가 · 규정 변경을 검증하고 배포하기

**흐름**　공개 중인 1판 → 2판 초안 작성 → 같은 시험 질문으로 비교 → 새 버전 공개 또는 이전 버전 복구

1. 내 체험용 Agent의 1판을 기준으로 삼는다. 2판 초안에서 대출 규정만 **“한 사람의 대출 한도는 5권입니다.”**로 교체한다.
2. 두 버전에 아래 세 질문을 실행한다. 답변과 근거에서 바뀌어야 할 항목과 그대로 유지돼야 할 항목을 비교한다.

| 시험 질문 | 1판 | 2판 초안 |
|---|---|---|
| 책을 몇 권까지 빌릴 수 있나요? | 3권과 1판의 대출 근거 | 5권과 2판의 대출 근거 |
| 일요일에도 여나요? | 일요일 휴관 | 일요일 휴관 |
| 분실물은 며칠 보관하나요? | 기간 확인 필요, 1층 안내데스크 안내 | 같은 안내 |

3. 저장 후 공유 링크에서 대출 한도 3권을 확인한다. 시험 결과가 기준에 맞으면 `새 버전 공개`를 누르고 같은 링크에서 5권을 확인한다.
4. 이전 버전 복구를 체험한다. 1판을 다시 공개한 뒤 같은 링크에 대출 질문을 넣는다.

**완료 기준**　초안 저장, 새 버전 공개, 이전 버전 복구 시점에 공유 링크의 답변이 각각 3권 → 5권 → 3권으로 바뀐다. 어떤 시험 결과를 근거로 공개를 결정했는지 설명할 수 있다.
